# Coffee Shop Sales Dashboard 

## Overview
This repository showcases an Excel-based sales dashboard created to analyze retail sales performance for a coffee shop.

## Project Focus
- Sales trends by day and hour  
- Monthly revenue overview  
- Store-level performance  
- Product and category insights  

## Deliverables
- Final dashboard screenshots  
- Summary document with objectives and recommendations  

## Tools Used
- Microsoft Excel  
  - Pivot Tables  
  - Pivot Charts  
  - Excel formulas  

## Scope
This repository highlights final outputs and insights.  
Detailed analysis logic and calculations are discussed during interviews.
